# Сугроб для Windows

Переносная версия для Windows 10/11 (64-разрядная). Распакуйте **весь архив** в отдельную
папку и запустите **Sugrob.exe**. Node.js, Python, Swift и установка зависимостей не нужны.
Не переносите один exe отдельно: рядом нужны DLL, ресурсы и остальные файлы Electron.

## Использование

- Окно настроек открывается при запуске. Выберите Москву, Рим, Афины,
  Санкт-Петербург, Токио, Флоренцию или Нижний Новгород — включится «Атмосфера города».
- Можно найти другой город. Для остальных мест доступен нейтральный сезонный образ.
- «Точная погода» показывает снег или дождь по погоде; без осадков экран чистый.
- «Атмосфера города» добавляет местный свет, редкие сезонные частицы и рисунки у края.
  Художественный свет не является точным прогнозом восхода или цветения растений.
- Атмосфера работает без сети. Реальные осадки обновляются каждые 15 минут;
  при ошибке сети старые осадки скрываются. Есть ручное обновление.
- Выключите выбранный город для ручного снега, дождя, листьев или лепестков.
- Настраиваются количество, скорость, размер, прозрачность, накопление у края окон
  и над панелью задач, реакция на курсор. «Пауза» останавливает анимацию.
- Каждый подключённый монитор получает свой прозрачный слой. Клики проходят сквозь него.
- Закрытие настроек оставляет приложение работающим. Открыть их можно снежинкой
  в трее или повторным запуском Sugrob.exe. «Выйти» завершает приложение.
- Для автозапуска сначала поместите папку в постоянное место, затем включите опцию.
  Перед перемещением или удалением папки выключите автозапуск.

Настройки хранятся в пользовательской папке приложения Electron (`%APPDATA%`).
Приложение не требует прав администратора. Сборка не подписана сертификатом издателя.

## Художественная атмосфера 1.2

Статические силуэты заменены фотографическими деталями, которые входят из-за правого
края, покачиваются и уходят. Есть кнопка «Показать движение сейчас» (вход занимает
около пяти секунд), мягкие движущиеся отблески и прозрачное изображение чайки.
PNG созданы ImageGen; это художественные AI-изображения, не фотографии конкретного города.

«Звуковой фон» выключен по умолчанию. При включении звучат локальные синтезированные
ветер, вода, шелест или дождь с плавным затуханием; это не полевые записи.
Громкость настраивается; пауза и выключение атмосферы останавливают звук.
На нескольких мониторах звук проигрывается только в одном слое.

Перед заменой файлов полностью выйдите из старого Sugrob через трей.

## Особенности Windows

Для координат окон запускается один скрытый процесс встроенного Windows PowerShell:
локальный код вызывает EnumWindows / DwmGetWindowAttribute каждые 500 мс.
Он не читает заголовки, содержимое окон или файлы и не передаёт эти данные в сеть.
При завершении приложения процесс останавливается. Если запуск запрещён политикой
компьютера, эффекты и накопление внизу остаются доступны, а в настройках показан статус.

Режима «позади всех окон, на обоях» в Windows-переносе пока нет.
Накопление на окнах и обработка полноэкранного режима требуют проверки на реальном
рабочем столе Windows, особенно с разным масштабом мониторов. Эксклюзивный полноэкранный
режим игр может закрывать эффекты. Скрытие при захвате зависит от программы захвата.

## Источники данных

[Open-Meteo](https://open-meteo.com/) / GeoNames. В сервис уходят только введённый
поисковый запрос и координаты выбранного города. Публичный API предназначен для
некоммерческого использования; условия: https://open-meteo.com/en/terms.

## Разработка и сборка

Нужен Node.js 22.12+ или 24+.

```sh
npm ci
npm test
npm start
npm run package
```

Результат: `dist/Sugrob-win32-x64/`. Для ARM64 задайте `SUGROB_ARCH=arm64`.
`package-lock.json` фиксирует зависимости; runtime Electron также закреплён.
Сборка может выполняться на macOS: Windows exe получается из официального runtime
Electron с добавлением ресурсов приложения. Для запуска всё равно нужна Windows.

В GitHub Actions добавлен `.github/workflows/windows.yml`: проверки логики,
сборка x64 / ARM64 и проверка запуска x64 на Windows. Workflow запустится после
публикации изменений в репозиторий. Локальная сборка на Mac не заменяет эту проверку.
