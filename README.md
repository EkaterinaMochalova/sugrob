# Сугроб

Снег, осенние листья, дождь или лепестки сакуры поверх рабочего стола macOS (13 Ventura и новее).

## Готовое приложение

После каждой отправки кода GitHub собирает приложение сам (работает и на Apple Silicon, и на Intel).

1. Откройте вкладку Actions в репозитории, выберите последний зелёный запуск и скачайте
   архив **Sugrob-app** внизу страницы. Нужно быть залогиненным в GitHub. Архив хранится 90 дней.
2. Распакуйте его, а внутри — `Sugrob.zip`. Перетащите `Sugrob.app` в «Программы».
3. Первый запуск: приложение не подписано сертификатом Apple, поэтому macOS его остановит.
   Откройте «Системные настройки → Конфиденциальность и безопасность», внизу нажмите
   «Всё равно открыть». Это нужно сделать один раз.

## Сборка на Mac

```sh
xcode-select --install          # один раз, если ещё нет инструментов разработчика
cd Sugrob
chmod +x build.sh && ./build.sh
cp -R build/Sugrob.app /Applications/
open /Applications/Sugrob.app
```

При первом запуске сразу откроется окно настроек.

## Как открыть настройки

- Снежинка в строке меню → «Настройки…» (⌘,).
- Значок в Dock, если включить его в настройках.
- Запустить Sugrob ещё раз через Spotlight (⌘Пробел → «Sugrob»), Launchpad или Finder.
  Этот путь работает всегда, даже если оба значка скрыты.

## Что умеет

- Режимы: снег, листья, дождь, лепестки. Пауза.
- Количество, скорость, размер, непрозрачность.
- Снег, листья и лепестки копятся сугробами на верхних краях окон и внизу экрана.
  Дождь проходит поверх окон; небольшие капли задерживаются на краях, стекают и исчезают.
- Сдвинули, закрыли или свернули окно — его сугроб осыпается.
  Если окно перекрыло чужой сугроб, перекрытая часть тоже осыпается.
- Курсор раскидывает сугробы и расталкивает падающие снежинки.
- «Сколько лежит» ограничивает число лежащих частиц: самые старые тают.
  «Смести всё» сдувает их сразу. Эта команда есть и в меню значка.
- Показ позади окон или поверх них, поверх полноэкранных приложений.
- Прятать эффект на скриншотах и при показе экрана. На новых версиях macOS
  это может не сработать.
- Автозапуск при входе в систему. Работает, если приложение лежит в /Applications.

Особых разрешений не нужно: положение окон и курсора macOS сообщает и без них.

## Погода в другом городе

В настройках откройте «Побыть в другом городе», введите название и нажмите «Найти».
Выберите подходящий результат с областью и страной — погодный режим включится сразу.
Город и включённый режим сохраняются между запусками. Геолокация не нужна.

- При снегопаде падает снег; при дожде, мороси или грозе — дождь.
- В режиме «Точная погода» при ясной погоде, облачности или тумане частицы скрыты.
- Температура и описание погоды показаны в настройках.
- Обновление — каждые 15 минут; есть кнопка «Обновить погоду».
- При ошибке сети реальные осадки скрываются, появляется сообщение. Можно повторить
  вручную или дождаться следующего обновления.
- «Пауза» продолжает работать. Количество, скорость и размер задаются вручную.
- Выключите «Включить выбранный город», чтобы вернуться к прежнему
  ручному режиму (снег, листья, дождь или лепестки).

Погода: [Open-Meteo](https://open-meteo.com/), поиск городов: Open-Meteo / GeoNames.
В сервис передаются поисковый запрос и координаты выбранного города.
Используется публичный API для некоммерческого использования; для коммерческого
распространения проверьте [условия сервиса](https://open-meteo.com/en/terms).

## Проверка погодного режима

```sh
bash tests/run.sh
```

Тесты используют локальные ответы API: проверяют коды осадков, поиск, ошибки HTTP/JSON,
сохранение города, восстановление после ошибки, отмену запросов и сохранность ручного режима.

## Окна в города — версия 1.3.3

В настройках выберите город и нажмите «Открыть окно в город».
Отдельное окно можно перемещать, изменять в размере и закрывать независимо от погоды.

- Москва: видео с трамваем.
- Рим: видео Пантеона.
- Афины: видео Акрополя.
- Санкт-Петербург: статичное фото.
- Токио: видео осеннего сада.
- Флоренция: видео Понте-Веккьо.

Нижний Новгород пока скрыт из списка готовых видов. Поиск других городов для погоды сохранён.
Видео зациклены. На Mac используется нативный AVPlayer, на Windows — веб-плеер с перекрёстным затуханием. Освещение автоматически следует местному
времени города с учётом летнего времени; ручных переключателей нет.
Это записанные виды с художественным освещением: сезон и события в кадре не являются
текущим наблюдением. Все материалы доступны локально. Реальная погода загружается отдельно.
Старые ветки и декоративные силуэты поверх рабочего стола отключены.

### Звуковой фон

По умолчанию выключен. Включается отдельным переключателем, есть громкость.
Используются оригинальные синтезированные петли ветра, воды, шелеста и дождя,
с плавным появлением и затуханием. Это звуковой образ, **не записи из городов**.
Пауза, выключение города и переход в точную погоду убирают звук.
При нескольких мониторах звучит только одна дорожка.

Фотографические PNG созданы встроенным ImageGen, сохранены в `assets/` с настоящим
альфа-каналом; точные промпты — `assets/prompts.json`. Это AI-изображения, не фотографии
из конкретных мест. Звуки воспроизводятся из локальных WAV, без загрузки аудио из сети.
Скрипт их создания — `scripts/make_ambience.py`.

Местное время учитывает часовой пояс и летнее время. Свет — стилизованное сезонное
расписание, а не расчёт восхода. Реальные осадки продолжают загружаться отдельно.

После обновления полностью выйдите из старого «Сугроба» через его меню, затем запустите
новую сборку: уже запущенный процесс сам не заменяется новой версией файла.
